# Дополнительный модуль скорости сети и wb-net

Эти два скрипта сохраняют пользовательскую настройку Waybar отдельно от базового
установщика Waybridge. `setup.sh` не включает её автоматически. На существующей
паре скрипты уже установлены; ниже приведена установка на другом компьютере.

## Возможности

- Реальная скорость приёма и отправки с 2–3 знаками после точки, например
  `12.34 KiB/s` и `12.345 KiB/s`. Интервал измерения — 5 секунд.
- `wb-net НОМЕР ОТВЕТ` принимает два целых числа в диапазоне **0–999**.
  Они отображаются как дробные части скоростей приёма и отправки: `3` → `.03`,
  `42` → `.42`, `123` → `.123`. Значения не являются измеренной скоростью.
- `wb-net clear` возвращает отображение измеренной скорости. Остановленный
  Waybridge также отключает применение подменённых значений. При следующем запуске
  сохранённое активное значение может примениться снова; для сброса используйте `clear`.
- Целая часть скорости и единица измерения по-прежнему зависят от реального трафика.
  JSON-подтверждение транспорта означает запись файла, а не обновление панели: оно
  появится на следующем цикле измерения.

## Установка

На клиенте из корня checkout:

```bash
install -Dm755 scripts/waybar-network.py ~/.local/libexec/waybar-network.py
```

В существующем конфиге Waybar добавьте `custom/network` в нужный список модулей
и описание модуля (не заменяйте весь конфиг):

```json
"custom/network": {
  "exec": "$HOME/.local/libexec/waybar-network.py",
  "return-type": "json",
  "restart-interval": 3
}
```

Перезагрузите свою панель Waybar. Нужны `python3` и команда `ip` из `iproute2`.
Скрипт выбирает доступный маршрут по умолчанию с наименьшей метрикой и читает
счётчики `/sys/class/net`; sudo и дополнительные сетевые порты не нужны.

На сервере из корня checkout:

```bash
install -Dm755 scripts/wb-net.py ~/.local/bin/wb-net
wb-net 123 999
wb-net clear
```

Нужна настроенная пара Waybridge: команда отправляет небольшой файл
`network-display.json` через существующий `waybridge send-code`. Оба устройства
должны иметь запущенный транспорт. По умолчанию получатель читает
`~/Documents/projects/network-display.json`; если изменён путь `projects` в
Waybridge, настройте константу `PAYLOAD` в скрипте получателя. Аналогично при
нестандартных путях конфигурации/state измените `BRIDGE` и `STOPPED`.

## Проверка и удаление

```bash
python3 scripts/waybar-network.py --once
wb-net --help
```

Отрицательные значения, числа больше 999, дроби и булевы значения в JSON
не принимаются. Символические ссылки и входные файлы больше 1024 байт отклоняются.
Перед изменением установленной настройки сохраните её резервную копию.

Для удаления сначала выполните `wb-net clear`, уберите `custom/network` из Waybar
и верните свой обычный модуль сети. Затем удалите `~/.local/bin/wb-net` на сервере
и `~/.local/libexec/waybar-network.py` на клиенте. Базовый uninstall Waybridge
не удаляет эти отдельно установленные скрипты персонализации.
