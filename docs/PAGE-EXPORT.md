# Экспорт текущего раздела страницы · 3.6 preview

## Что получается

На клиенте пользователь включает **«Тема Nord»** в расширении
**Nordic Reader**.
Расширение собирает доступный текст, порядок вопросов и вариантов, текущие значения
полей и PNG-фрагменты всего текущего документа. В Google Forms это текущий раздел,
а не все ещё не открытые разделы анкеты. На ПК создаётся автономная HTML-страница
для чтения с выделяемым текстом, состоянием полей и оригинальным видом раздела.

В HTML нет исходных скриптов формы, активных полей или внешних ресурсов. Изображения
встроены как проверенные PNG. Его можно открыть после отключения сети. Исходные
URL сохраняются без query/fragment; cookies, localStorage и HTTP-заголовки не читаются.
Снимок визуального содержимого может включать введённые пользователем данные.
Экспорт приватных вкладок отключён.

## Установка на существующую пару

На обоих устройствах обновите checkout до `v3.6.0-rc.3`:

```bash
git fetch --tags origin
git switch --detach v3.6.0-rc.3
bash setup.sh --update
waybridge start
waybridge check
```

Для первой установки используйте мастер из README. На ПК для автоматического
открытия HTML нужен `xdg-open` из пакета `xdg-utils`; при свежей установке мастер
установит его. Обновление `--update` не устанавливает системные пакеты.

Мастер клиента устанавливает:

- файлы расширения: `~/.local/share/waybridge/firefox-export/`;
- native host: `~/.local/libexec/waybridge-page-native`;
- манифест `org.waybridge.page_export.json` в пользовательские каталоги Mozilla
  `~/.mozilla/native-messaging-hosts/` и `~/.config/mozilla/native-messaging-hosts/`
  для совместимости с размещением данных Firefox.

Manifest разрешает вызов только расширению `page-export@waybridge.local`.
Новые слушающие порты, системные службы и ключи не создаются.

## Загрузка расширения для локальной проверки

1. В обычном Firefox откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите `~/.local/share/waybridge/firefox-export/manifest.json`.
4. Если старая версия уже загружена, нажмите **«Перезагрузить»** рядом с ней.
5. Откройте страницу формы и меню **Nordic Reader**.
6. Включите **«Тема Nord»**. Firefox запросит дополнительное разрешение
   доступа к вкладкам: оно требуется API `tabs.captureTab` для полного снимка.
   Если запрос разрешения закрыл popup, откройте меню и проверьте, что переключатель включён.

Расширение не устанавливает обработчики клавиатуры. Широкое разрешение
`<all_urls>` запрашивается отдельно для оформления сайтов и API `captureTab`.
Разрешение `storage` сохраняет только состояние переключателя.

## Nordic и автоматические разделы

По умолчанию режим выключен. Включение переключателя одновременно включает
тёмное оформление обычных HTTP/HTTPS-сайтов и автоматическую отправку активных
неприватных вкладок `https://docs.google.com/forms/.../viewform` и `formResponse`.
Поддерживаются новые адреса `/forms/d/.../viewform` и старые публичные/встроенные
адреса `/forms/viewform?id=...`, в том числе с дополнительными параметрами оформления.
Один общий модуль распознаёт адрес и в фоне, и в документе. Старый `id` сохраняется
в каноническом пути `/forms/d/ID/viewform`; остальные query/fragment отбрасываются.
Поддерживается извлечение заголовков из старых `.ss-form-question` / `.ss-q-title`.
Прочие сайты автоматически не отправляются. В компактном popup один общий переключатель: он включает и тему, и отправку
разделов. Предупреждения и ошибки появляются только при необходимости. Постоянной надписи
на значке при включённом режиме нет.

На уже открытых вкладках тема применяется сразу; на новых — после загрузки.
Используется локально включённый Dark Reader API 4.9.133, без CDN-скриптов,
с цветами Nord `#2e3440` / `#d8dee9`. Это самостоятельное расширение, а не
официальный Dark Reader. Лицензия и происхождение библиотеки — в
[THIRD-PARTY.md](THIRD-PARTY.md). На защищённых браузером страницах тема не применяется.

Изменения документа отслеживает MutationObserver. Через 1,4 секунды после
изменения доступного раздела создаётся снимок; переходы между разделами Forms
обрабатываются без нажатия кнопки расширения. Выбор ответа, печать и прокрутка
сами по себе не создают новую копию: ключ включает URL, заголовок, тексты вопросов
и порядок вариантов, но исключает значения полей, выбор и прокрутку.
Снимок содержит состояние полей на момент захвата, это не журнал всех изменений
ответов. Для повторного снимка выключите и снова включите режим на нужном разделе.

Очередь: до 3 разделов и 64 МиБ сериализованных данных в RAM. Один пакет — до
32 МиБ. Во время отправки можно подготовить следующий раздел. При переполнении
новый раздел не заменяет старые; текущий открытый раздел повторяет попытку
через 5 секунд. Подтверждённые ключи последних 64 разделов подавляют дубликаты.
Повтор после ошибки сети — через 15 секунд с тем же UUID. Неполный снимок
останавливает очередь до отдельного подтверждения в меню.

Дождитесь сообщения «Раздел сохранён на ПК», прежде чем закрывать вкладку.
Очень быстрые переходы до завершения захвата могут не сохраниться: расширение
не задерживает навигацию и не открывает скрытые разделы само. Если данные
изменились во время захвата, они не отправляются и текущая страница пробуется снова.

Выключение переключателя возвращает исходное оформление, отключает наблюдатели,
очищает автоматическую очередь и разрывает активный native-канал. SSH-процесс
завершается при завершении native host. Уже сохранённый на ПК снимок не удаляется;
подтверждение могло ещё не успеть вернуться. Основной транспорт Waybridge управляется отдельно. Win+Z по-прежнему останавливает весь транспорт.

Состояние переключателя сохраняется между запусками Firefox, очередь — нет.
После падения/закрытия браузера неотправленные снимки не восстанавливаются.
Для полного отключения режима выключите переключатель, а не только закройте popup.

Временное дополнение пропадает после перезапуска Firefox. Настройки подписей не
изменяются. Постоянная установка в release Firefox требует подписи Mozilla:
[Signing and distribution overview](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Получение на ПК

Доставка использует существующий `bridge-shot` SSH alias и тот же forced command.
Новый префикс `WBP1` отличает страницу от `WB1` PNG. UUID, длина и SHA-256 сверяются
до публикации. JSON и HTML записываются атомарно с fsync; ACK возвращается после
их сохранения. Повтор того же пакета с тем же ID не создаёт дубликат. Конфликт ID
с другим содержимым отклоняется.

Каталог: `~/.cache/bridge/pages/`. Сохраняются последние 10 пар JSON/HTML.
`latest.json` указывает ID последнего сохранённого снимка. Уже работающий обработчик
галереи замечает новую страницу и запускает `xdg-open` в отдельном transient unit
systemd пользователя. Ошибка открытия не означает потерю сохранённого файла:
его можно открыть вручную из каталога. ACK подтверждает сохранение, а не отображение.

## Ошибки и повтор

- Передача: до 3 попыток по 45 секунд внутри native host. Незавершённый снимок
  остаётся в RAM расширения; автоматический повтор использует тот же пакет и UUID.
- Закрытие Firefox очищает RAM; восстановления после перезапуска браузера нет.
- `waybridge stop` запрещает новые передачи и прерывает текущую native-передачу
  при проверке маркера остановки. Он не выгружает само дополнение из Firefox и
  не очищает уже подготовленный снимок в памяти расширения.
- Если документ изменился между чтением и окончанием захвата, пакет не отправляется.
  Не вводите текст и не меняйте раздел во время экспорта.
- Неполные изображения, встроенные фреймы и нераспознанные вопросы показываются
  как предупреждения. Для отправки нужен отдельный клик **«Отправить с предупреждениями»**.
- Для закрытых пользовательских dropdown не гарантируется получение ещё не
  загруженных вариантов. Их текущий вид остаётся на изображении. Для сложных
  таблиц и сеток сверяйтесь с оригинальным видом, а не только плоским списком.
- Размер пакета: максимум 32 МиБ. Документ: ширина до 8192 CSS px, высота до
  100000 CSS px, площадь до 80 млн пикселей; PNG-фрагменты высотой до 4096 px.
  При превышении экспорт отклоняется, а не обрезается молча.

Браузер может не отрисовать отложенное содержимое, пока оно не было загружено.
Экспорт не переключает разделы и не раскрывает элементы автоматически. Снимок
доказывает только сохранение доступного документа в момент захвата.

## Постоянная установка

Соберите неподписанный пакет:

```bash
python scripts/build-extension.py --output waybridge-page-export-unsigned.xpi
```

В аккаунте разработчика Mozilla загрузите пакет для **самостоятельного
распространения / unlisted**, пройдите проверку и скачайте подписанный XPI.
В Firefox откройте `about:addons` → меню настроек → **«Установить дополнение из файла»**.
Native manifest уже установлен мастером; ID подписанного дополнения должен
оставаться `page-export@waybridge.local`.

Неподписанный XPI из GitHub release предназначен для временного тестирования,
он не является подписанным установщиком. Публикация в AMO и результат её проверки
не выполняются автоматически без аккаунта владельца.

## Разработка

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
# Dev-only: Node 22+, Playwright 1.62.1 and its Chromium.
node tests/browser-pages.cjs
node tests/nordic.cjs
# Uses the installed Firefox, a fresh temporary profile and loopback BiDi.
node tests/firefox-pages.cjs
```

Firefox integration test temporarily installs a test clone that pre-grants
capture permission and exports only the bundled fixture. Its temporary profile,
remote-debugging listener and helper code are removed after the test. It never
attaches to the user's existing browser or changes that profile's preferences.
